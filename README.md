# Snap-Mart - Multivendor eCommerce Platform

Snap-Mart is a modern full-stack multivendor eCommerce platform built with Next.js. The application allows multiple vendors to manage products, orders, and customers while providing users with a fast, secure, and responsive shopping experience.

The project is designed with scalable architecture, smooth UI animations, secure authentication, and modern frontend technologies to simulate a real-world marketplace like Amazon or Flipkart.

---

## Features

* Multi Vendor Marketplace
* User Authentication & Authorization
* Vendor Dashboard
* Product Management
* Shopping Cart & Checkout
* Order Tracking System
* Responsive Modern UI
* Smooth Animations & Motion Effects
* Secure Backend APIs
* Mobile Friendly Design
* Admin Management System

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open http://localhost:3000 with your browser to see the result.

You can start editing the application by modifying the project files. The page auto-updates as you edit the files.
